# Media

- `screenshots/`: the Streamlit app running in mock mode (inbox, a complaint escalated to a person, a warranty email routed to its tools, the audit log).
- `manim/`: the explainer animations used in the video (3Blue1Brown's manim, `manimgl`). `videos/` has the renders, `stills/` the last frame of each, and `fde_visuals.py` the source. Render one with `manimgl fde_visuals.py Architecture -w` from this folder (needs the Inter Tight font registered, see the top of the file).
- `screen-recordings/`: the screen recordings from the video go here.
